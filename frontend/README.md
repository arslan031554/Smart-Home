# Smart Home Configurator Frontend

React + Vite SPA for the customer configurator and admin/backoffice.

## Delivered modules
- landing page and customer auth flow
- guest configurator with draft persistence and recovery
- authenticated dashboard and offer screens
- admin backoffice pages
- EN/RO translations

## Start locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```
