# Smart Building Configurator Frontend Handoff

## Delivered capability
- guest start configurator flow
- account creation + OTP verification
- guest draft attach after login/verification
- multi-step configurator with summary and offer generation
- customer dashboard and admin backoffice
- EN/RO translations

## Local run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
