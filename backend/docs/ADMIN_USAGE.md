# Admin Usage

## Before quoting works correctly
1. create building types and descriptions
2. map room types to building types
3. create smart functions and map them to room types
4. create ranges and colors
5. create products and map functions/channels/ranges/colors
6. create services and map them to smart functions
7. configure discount rules
8. review offer conditions and disclaimers

## Important QA focus
- hidden/internal ranges and colors
- product channel capacities
- service pricing mode
- discount rule ordering
